三者的关系和差异，从架构、功能、使用场景全面对比。

核心定位

工具 定位 底层运行时 目标用户
Docker 完整的容器平台 dockerd → containerd 所有容器用户
nerdctl Docker 兼容的 containerd 客户端 containerd 直接 需要轻量级方案的用户
ctr containerd 的低级调试工具 containerd 直接 开发者、系统管理员

功能完整对比表

1. 镜像管理

功能 Docker nerdctl ctr 说明
拉取镜像 docker pull nerdctl pull ctr image pull 都支持
推送镜像 docker push nerdctl push ctr image push 都支持
构建镜像 docker build nerdctl build ❌ ctr 不支持
列出镜像 docker images nerdctl images ctr image ls 都支持
删除镜像 docker rmi nerdctl rmi ctr image rm 都支持
标记镜像 docker tag nerdctl tag ctr image tag 都支持
镜像历史 docker history nerdctl history ❌ ctr 不支持
保存镜像 docker save nerdctl save ctr image export 命令不同
加载镜像 docker load nerdctl load ctr image import 命令不同
搜索镜像 docker search nerdctl search ❌ ctr 不支持
镜像检查 docker inspect nerdctl inspect ctr image ls -q ctr 功能弱
多架构构建 docker buildx nerdctl build --platform ❌ Docker 功能最强
镜像缓存 ✅ ✅ ✅ 都支持
镜像层优化 ✅ ✅ ⚠️ ctr 无优化

重启容器 docker restart nerdctl restart ❌ ctr 不支持
删除容器 docker rm nerdctl rm ctr container rm 都支持
查看日志 docker logs nerdctl logs ❌ ctr 不支持

容器检查 docker inspect nerdctl inspect ctr container info 输出格式不同
