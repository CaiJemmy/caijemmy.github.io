Optional 是 Python 类型注解系统中的一个重要类型，用于表示一个值可以是某个类型或者 None。

基本语法

1# 表示参数 name 可以是 str 类型，也可以是 None
2
3from typing import Optional
4
5def greet(name: Optional[str]) -> str:
6    if name is None:
7        return "Hello, stranger!"
8    return f"Hello, {name}!"

Optional 的本质

Optional[T] 等价于 Union[T, None]

1from typing import Optional, Union
2
3# 这两种写法完全等价
4def func1(x: Optional[str]) -> None: ...
5def func2(x: Union[str, None]) -> None: ...
6
7# Python 3.10+ 还可以这样写
8def func3(x: str | None) -> None: ...

默认值示例

1def find_user(user_id: int) -> Optional[str]:
2    """查找用户名，如果找不到返回 None"""
3    users = {1: "Alice", 2: "Bob"}
4    return users.get(user_id)  # 可能返回 None
5
6user = find_user(1)  # 类型: Optional[str]
7user = find_user(99)  # 类型: Optional[str] (实际上是 None)

5. 最佳实践

5.1 总是检查 None

 1# ❌ 不好的做法
 2def process_data(data: Optional[str]) -> str:
 3    return data.upper()  # 如果 data 是 None 会崩溃
 4
 5# ✅ 好的做法
 6def process_data(data: Optional[str]) -> str:
 7    if data is None:
 8        return ""
 9    return data.upper()
10
11# ✅ 使用 walrus 操作符 (Python 3.8+)
12def process_data(data: Optional[str]) -> str:
13    if (normalized_data := data) is not None:
14        return normalized_data.upper()
15    return ""

5.2 避免过度使用 Optional

 1# ❌ 过度使用
 2def process(
 3    data: Optional[str] = None,
 4    count: Optional[int] = None,
 5    enabled: Optional[bool] = None
 6) -> Optional[Dict]:
 7    pass
 8
 9# ✅ 更好的设计
10def process(
11    data: str = "",
12    count: int = 0,
13    enabled: bool = False
14) -> Dict:
15    pass

5.3 使用类型保护

1from typing import Optional, List
2
3def process_items(items: Optional[List[str]]) -> None:
4    """类型保护：确保 items 不是 None"""
5    if items is None:
6        items = []  # 现在 items 是 List[str]，不是 Optional[List[str]]
7    
8    for item in items:  # 安全访问，IDE 不会警告
9        print(item.upper())

6. 与 None 的对比

 1# 没有类型注解
 2def old_style(value):  # value 可以是任何类型
 3    if value is None:
 4        return "None"
 5    return str(value)
 6
 7# 有类型注解
 8def new_style(value: Optional[str]) -> str:
 9    # IDE 知道 value 可能是 str 或 None
10    if value is None:
11        return "None"
12    return value.upper()  # IDE 知道这里 value 一定是 str

9. 常见错误

9.1 忘记检查 None

1def get_length(data: Optional[str]) -> int:
2    return len(data)  # ❌ 如果 data 是 None 会崩溃
3
4# 修复
5def get_length(data: Optional[str]) -> int:
6    return len(data) if data is not None else 0

9.2 错误的默认值

1# ❌ 错误：默认值类型不匹配
2def func(data: Optional[str] = []) -> None:  # 列表不是 Optional[str]
3    pass
4
5# ✅ 正确
6def func(data: Optional[str] = None) -> None:
7    data = data or ""  # 使用默认值

总结

Optional 的主要用途：

  1. 明确表达"可能不存在"的语义
  2. 提高代码可读性和可维护性
  3. 让IDE和类型检查器提供更好的支持
  4. 减少运行时错误

记住：Optional[T] 就是 Union[T, None] 的语法糖，它让代码的意图更加清晰。
