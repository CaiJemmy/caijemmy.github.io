shell 中常见的文件测试运算符

常见的文件测试运算符

运算符 含义 示例
-e 文件/目录是否存在 [ -e file ]
-f 是否是普通文件 [ -f file ]
-d 是否是目录 [ -d dir ]
-L 或 -h 是否是符号链接 [ -L link ]
-r 是否可读 [ -r file ]
-w 是否可写 [ -w file ]
-x 是否可执行 [ -x file ]
-s 文件大小是否 > 0 [ -s file ]
-z 字符串长度是否为 0 [ -z "$var" ]
-n 字符串长度是否 > 0 [ -n "$var" ]

完整的参数扩展语法表

语法 含义 示例
${var:-default} 默认值替换，如果 var 未设置或为空，使用 default ${name:-guest}
${var-default} 如果 var 未设置，使用 default（空值不算） ${name-guest}
${var:=default} 默认值赋值，如果 var 未设置或为空，设置 var=default ${name:=guest}
${var=default} 如果 var 未设置，设置 var=default（空值不算） ${name=guest}
${var:?error} 未定义时报错 ${name:?"未定义"}
${var:+repl} 非空时替换 ${name:+[set]}
${#var} 字符串长度 ${#name}
${var:start} 子字符串 ${name:2}
${var:start:len} 子字符串 ${name:2:3}
${var#pattern} 删除前缀（最短） ${name#*/}
${var##pattern} 删除前缀（最长） ${name##*/}
${var%pattern} 删除后缀（最短） ${name%.*}
${var%%pattern} 删除后缀（最长） ${name%%.*}
${var/old/new} 替换第一个 ${name/old/new}
${var//old/new} 替换全部 ${name//old/new}
