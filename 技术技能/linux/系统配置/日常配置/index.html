Linux PAM

/etc/security/limits.conf 及 /etc/security/limits.d/这两个文件是 Linux PAM（Pluggable Authentication Modules） 的一部分，用于限制用户和进程的系统资源使用。它们定义了各种资源限制，如打开文件数、进程数、内存使用等。

为什么需要 PAM 配置？

limits.conf 本身不会自动生效，需要 PAM 模块在用户登录时应用这些限制，常见的 PAM 配置文件：

  • /etc/pam.d/login # 控制台登录
  • /etc/pam.d/sshd # SSH 登录
  • /etc/pam.d/su # su 切换用户
  • /etc/pam.d/common-session # 通用会话配置（Debian/Ubuntu）
 1# /etc/security/limits.conf
 2# 进程数限制
 3#[ -e /etc/security/limits.d/*nproc.conf ] && rename nproc.conf nproc.conf_bk /etc/security/limits.d/*nproc.conf
 4for file in /etc/security/limits.d/*nproc.conf
 5do
 6    rename "${file}" "${file}_bak"
 7done
 8
 9# 确保 limits.conf 配置能够生效（通过 PAM 模块）
10[ -z "$(grep 'session required pam_limits.so' /etc/pam.d/common-session)" ] && echo "session required pam_limits.so" >> /etc/pam.d/common-session
11
12sed -i '/^# End of file/,$d' /etc/security/limits.conf
13cat >> /etc/security/limits.conf <<EOF
14# End of file
15* soft nproc 1000000
16* hard nproc 1000000
17* soft nofile 1000000
18* hard nofile 1000000
19root soft nproc 1000000
20root hard nproc 1000000
21root soft nofile 1000000
22root hard nofile 1000000
23EOF
24# *：所有用户
25# soft nproc 1000000：软限制 - 最大进程数 1,000,000
26# hard nproc 1000000：硬限制 - 最大进程数 1,000,000
27# soft nofile 1000000：软限制 - 最大打开文件数 1,000,000
28# hard nofile 1000000：硬限制 - 最大打开文件数 1,000,000

Linux 内核参数的永久配置文件

/etc/sysctl.conf 是 Linux 内核参数的永久配置文件，用于在系统启动时设置内核参数。这些参数控制着系统的各种行为，包括网络、内存、文件系统等。

 1# 主配置文件
 2/etc/sysctl.conf
 3
 4# 配置片段目录（推荐使用）
 5/etc/sysctl.d/*.conf
 6
 7# 运行时查看当前值
 8sysctl -a
 9
10# 临时修改（重启失效）
11sysctl -w parameter=value
12
13# 加载配置文件
14sysctl -p [filename]

一、文件系统参数

参数 默认值 推荐值 作用 重要性 影响

2.1 连接管理

参数 默认值 推荐值 作用 重要性 影响

注意事项

  1. 参数间依赖：某些参数有依赖关系，如 tcp_tw_reuse 需要 tcp_timestamps=1
  2. 系统兼容性：不同内核版本参数可能不同
  3. 硬件限制：参数设置不能超过硬件能力
  4. 逐步调整：生产环境应逐步调整并监控效果
  5. 备份配置：修改前备份原配置
  6. 测试验证：修改后进行全面测试
  7. 监控指标：关注连接数、内存使用、CPU 负载等指标
  8. 文档记录：记录所有修改和调整原因

/etc/sysctl.d/ 是 Linux 系统中用于存放 内核参数配置片段 的目录。与传统的 /etc/sysctl.conf 文件相比，使用这个目录有以下优点：

 1bash# 目录结构示例
 2/etc/sysctl.d/
 3├── 00-system.conf      # 系统基础配置
 4├── 10-network.conf     # 网络相关配置
 5├── 20-security.conf    # 安全相关配置
 6├── 30-performance.conf # 性能优化配置
 7├── 50-default.conf     # 默认配置
 8├── 60-custom.conf      # 自定义配置
 9├── 90-override.conf    # 覆盖配置
10└── 99-sysctl.conf      # 最终配置（兼容性）

 27set_limits() {
 28    # /etc/security/limits.conf
 29    # 进程数限制
 30    #[ -e /etc/security/limits.d/*nproc.conf ] && rename nproc.conf nproc.conf_bk /etc/security/limits.d/*nproc.conf
 31    for file in /etc/security/limits.d/*nproc.conf; do

 33    done
 34
 35    # 确保 limits.conf 配置能够生效（通过 PAM 模块）
 36    [ -z "$(grep 'session required pam_limits.so' /etc/pam.d/common-session)" ] && echo "session required pam_limits.so" >>/etc/pam.d/common-session
 37
 38    MEM_MB=$(free -m | awk '/^Mem:/{print $2}')
 39    # 计算合理的限制
 40    if [ $MEM_MB -lt 1024 ]; then
 41        # 小于 1GB 内存
 42        MAX_PROC=4096
 43        MAX_FILE=65535
 44    elif [ $MEM_MB -lt 4096 ]; then
 45        # 1-4GB 内存
 46        MAX_PROC=16384
 47        MAX_FILE=131072
 48    elif [ $MEM_MB -lt 16384 ]; then
 49        # 4-16GB 内存
 50        MAX_PROC=65536
 51        MAX_FILE=262144
 52    else
 53        # 大于 16GB 内存
 54        MAX_PROC=262144
 55        MAX_FILE=524288
 56    fi
 57
 58    sed -i '/^# End of file/,$d' /etc/security/limits.conf
 59    cat >>/etc/security/limits.conf <<EOF
