04 keepalived

在使用keepalived之前，DR模式的实验面临的问题

  • LVS单节点，如果节点故障或LVS服务问题，业务受影响。（单节点问题）
  • RS节点异常，lvs 请求分发到异常节点，业务受影响。

解决办法

  • 单节点 -> 多节点（主主方式，主备方式）
  • 判断RS挂的方式：http 协议的请求，返回 200，OK

要能自动切换主从节点；

要能自动探测RS是否正常，异常时摘除相应节点，不再向异常节点转发。

LVS-DR + Keepalived 高可用

1 Real Server 配置（所有节点，DR模式）

 1#!/bin/bash
 2# scripts/realserver_dr.sh
 3# Support Multiple VIPs
 4
 5# VIP列表（用空格分隔）
 6VIPS="10.0.0.200 10.0.0.201 10.0.0.202"
 7
 8case "$1" in
 9    start)
10        echo "Starting RealServer DR configuration..."
11        
12        for VIP in ${VIPS}; do
13            echo "Configuring VIP: ${VIP}"
14            
15            # 配置IP
16            ip addr add ${VIP}/32 dev lo label lo:0 2>/dev/null
17            
18            # 添加路由
19            ip route add ${VIP}/32 dev lo scope host 2>/dev/null
20        done
21        
22        # 配置ARP（所有VIP共享）
23        echo "1" > /proc/sys/net/ipv4/conf/lo/arp_ignore
24        echo "2" > /proc/sys/net/ipv4/conf/lo/arp_announce
25        echo "1" > /proc/sys/net/ipv4/conf/all/arp_ignore
26        echo "2" > /proc/sys/net/ipv4/conf/all/arp_announce
27        
28        echo "RealServer Start OK"
29        ;;
30        
31    stop)
32        echo "Stopping RealServer DR configuration..."
33        
34        for VIP in ${VIPS}; do
35            echo "Removing VIP: ${VIP}"
36            
37            # 删除路由
38            ip route del ${VIP}/32 dev lo 2>/dev/null
39            
40            # 删除IP
41            ip addr del ${VIP}/32 dev lo 2>/dev/null
42        done
43        
44        echo "RealServer Stop OK"
45        ;;
46        
47    status)
48        echo "=== RealServer Status ==="
49        echo "Configured VIPs: ${VIPS}"
50        echo ""
51        
52        for VIP in ${VIPS}; do
53            if ip addr show lo | grep -q "${VIP}/32"; then
54                echo "✓ ${VIP} - ACTIVE"
55            else
56                echo "✗ ${VIP} - INACTIVE"
57            fi
58        done
59        
60        echo ""
61        echo "ARP Configuration:"
62        echo "  arp_ignore: $(cat /proc/sys/net/ipv4/conf/all/arp_ignore)"
63        echo "  arp_announce: $(cat /proc/sys/net/ipv4/conf/all/arp_announce)"
64        ;;
65        
66    *)
67        echo "Usage: $0 {start|stop|status}"
68        exit 1
69esac

使用 sysctl 持久化 ARP 配置

 1#!/bin/bash
 2# /etc/keepalived/scripts/realserver_dr_persistent.sh
 3
 4VIP=10.0.0.200
 5
 6case "$1" in
 7    start)
 8        # 配置lo接口
 9        ip addr add ${VIP}/32 dev lo label lo:0 2>/dev/null
10        ip link set lo up
11        
12        # 添加路由
13        ip route add ${VIP}/32 dev lo scope host 2>/dev/null
14        
15        # 配置ARP（持久化）
16        cat >> /etc/sysctl.conf <<EOF
17# LVS DR Mode ARP Configuration
18net.ipv4.conf.lo.arp_ignore = 1
19net.ipv4.conf.lo.arp_announce = 2
20net.ipv4.conf.all.arp_ignore = 1
21net.ipv4.conf.all.arp_announce = 2
22EOF
23        
24        # 应用配置
25        sysctl -p
26        
27        echo "RealServer Start OK (with persistent ARP config)"
28        ;;
29        
30    stop)
31        # 删除路由和IP
32        ip route del ${VIP}/32 dev lo 2>/dev/null
33        ip addr del ${VIP}/32 dev lo 2>/dev/null
34        
35        # 清理sysctl配置（可选）
36        sed -i '/# LVS DR Mode ARP Configuration/,+4d' /etc/sysctl.conf
37        
38        echo "RealServer Stop OK"
39        ;;
40        
41    *)
42        echo "Usage: $0 {start|stop}"
43        exit 1
44esac

2 测试keepalived主备切换

测试步骤：停主节点keepalived服务，查看备节点上的VIP地址，再次启动主节点keepalived服务，查看VIP地址有没有从备迁移到主。期望是不迁移。如果迁移了，请从以下步骤排查。

  • 检查备节点配置nopreempt：如果没有配置，vrrp_instance中增加nopreempt。
  • 检查主节点配置state：是不是配置的state MASTER，

nopreempt（非抢占模式）只在 state BACKUP 的节点上生效。当主节点是 MASTER 状态时，它恢复后会无视 nopreempt，直接抢回 VIP。

正确的非抢占配置

节点 state priority nopreempt 行为
主节点 BACKUP 100 配置 初次启动时优先级高会成为 MASTER
备节点 BACKUP 90 配置 成为 MASTER 后不会被抢占
