02 DR模式实验

DR 模式的关键是：

  • Director 和 Real Server 必须处于同一个二层广播域；
  • VIP 同时配置在 Director 和 Real Server 上；
  • Real Server 必须避免对 VIP 的 ARP 请求进行响应；
  • Director 只修改目标 MAC，不修改 IP 和端口；
  • Real Server 的响应绕过 Director，直接返回客户端。
