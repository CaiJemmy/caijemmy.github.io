虚拟服务管理命令

​
 1ipvsadm -A|E virtual-service [-s scheduler] [-p [timeout]] [-M netmask] [--pe persistence_engine] [-b sched-flags]
 2
 3# 添加虚拟服务 -A
 4# 修改虚拟服务 -E
 5# virtual-service   -t VIP:PORT tcp服務 | -u VIP:PORT  udp服務 | -f MARK  FWM（防火墙标记）服务
 6# -s scheduler  one of rr|wrr|lc|wlc|lblc|lblcr|dh|sh|sed|nq|fo|ovf|mh, the default scheduler is wlc.
 7
 8# -p [timeout] 在指定时间内，来自同一客户端的请求调度到同一RS，实现会话保持，持久超时时间（秒）
 9# -M NETMASK   持久粒度掩码（默认255.255.255.255）
10
11# 添加 TCP 80 端口服务，使用轮询算法
12ipvsadm -A -t 192.168.1.100:80 -s rr
13
14# 将调度算法从 rr 改为 wrr
15ipvsadm -E -t 192.168.1.100:80 -s wrr
​
1ipvsadm -D virtual-service
2
3# 删除 TCP 80 服务
4ipvsadm -D -t 192.168.1.100:80

静态调度算法

算法 代码 说明 适用场景
轮询 rr 依次分配给每个RS RS性能相近
加权轮询 wrr 按权重比例分配 RS性能不同
目标地址哈希 dh 根据目标IP哈希 特定目标固定RS
源地址哈希 sh 根据源IP哈希 会话保持

动态调度算法

算法 代码 说明 适用场景
最少连接 lc 选择连接数最少的RS 长连接服务
加权最少连接 wlc 结合权重和连接数 性能不同+长连接
最短期望延迟 sed (活动连接+1)/权重最小 均衡负载
永不排队 nq 无需等待的最少连接 短连接
基于局部性的最少连接 lblc 目标IP哈希+最少连接 缓存集群
带复制的lblc lblcr lblc+复制 高可用缓存

真实服务器管理命令

​
 1ipvsadm -a|e virtual-service -r server-address [options]
 2
 3# 添加真实服务器 -a
 4# 修改真实服务器 -e
 5# virtual-service   -t VIP:PORT tcp服務 | -u VIP:PORT  udp服務 | -f MARK  FWM（防火墙标记）服务
 6# -r server-address  真实服务器 RIP:PORT
 7
 8# options  一般为这些参数 -g|-i|-m [-w WEIGHT]
 9#    --gatewaying   -g                   gatewaying (direct routing) (default)
10#    --ipip         -i                   ipip encapsulation (tunneling)
11#    --masquerading -m                   masquerading (NAT)
12#    --weight       -w weight            capacity of real server 取值范围：0-65535，权重为1（默认），权重为0（停止调度新连接，但保持现有连接）
13
14ipvsadm -a -t 192.168.1.100:80 -r 192.168.1.11:80 -g -w 1
15ipvsadm -a -t 192.168.1.100:80 -r 192.168.1.12:80 -g -w 1
16
17# 修改权重
18ipvsadm -e -t 192.168.1.100:80 -r 192.168.1.11:80 -g -w 5
19
20# 改变转发模式（不推荐）
21ipvsadm -e -t 192.168.1.100:80 -r 192.168.1.11:80 -m -w 1
​
1ipvsadm -d virtual-service -r server-address
2
3# 删除单个RS
4ipvsadm -d -t 192.168.1.100:80 -r 192.168.1.11:80

查看信息

列出规则 -L

数字格式 -n

​
1root@debian:~# ipvsadm -Ln
2IP Virtual Server version 1.2.1 (size=4096)
3Prot LocalAddress:Port Scheduler Flags
4  -> RemoteAddress:Port           Forward Weight ActiveConn InActConn
5TCP  10.0.0.200:80 rr
6  -> 10.0.0.129:80                Route   1      0          0
7  -> 10.0.0.130:80                Route   1      0          0

列说明：

  • Prot：协议（TCP/UDP/FWMARK）
  • LocalAddress:Port：VIP和端口
  • Scheduler：调度算法
  • Forward：转发模式 （ Route：DR模式 | Masq：NAT模式 | Tunnel：TUN模式）
  • Weight：权重
  • ActiveConn：活动连接数
  • InActConn：非活动连接数

查看连接表 -c

​
1root@debian:~# ipvsadm -Lnc
2IPVS connection entries
3pro expire state       source             virtual            destination
4TCP 01:55  FIN_WAIT    10.0.0.1:22498     10.0.0.200:80      10.0.0.130:80
5TCP 01:54  FIN_WAIT    10.0.0.1:22496     10.0.0.200:80      10.0.0.130:80
6TCP 01:54  FIN_WAIT    10.0.0.1:22497     10.0.0.200:80      10.0.0.129:80
7TCP 01:53  FIN_WAIT    10.0.0.1:22494     10.0.0.200:80      10.0.0.130:80

列说明：

  • pro：协议
  • expire：连接剩余时间（分:秒）
  • state：TCP连接状态 （ESTABLISHED：已建立 | SYN_RECV：收到SYN | FIN_WAIT：等待关闭 | TIME_WAIT：等待超时 | CLOSE：已关闭）
  • source：客户端IP:端口
  • virtual：VIP:端口
  • destination：RS IP:端口

查看统计信息 --stats

​
1root@debian:~# ipvsadm -Ln --stats
2IP Virtual Server version 1.2.1 (size=4096)
3Prot LocalAddress:Port               Conns   InPkts  OutPkts  InBytes OutBytes
4  -> RemoteAddress:Port
5TCP  10.0.0.200:80                      32      319        6    53747      528
6  -> 10.0.0.129:80                      16      207        2    44703      176
7  -> 10.0.0.130:80                      16      112        4     9044      352

列说明：

  • Conns：累计连接数
  • InPkts：入站数据包数
  • OutPkts：出站数据包数（NAT模式才有）
  • InBytes：入站字节数
  • OutBytes：出站字节数（NAT模式才有）

用途：

  • 验证负载是否均衡
  • 监控流量分布
  • 故障排查

查看速率 --rate

​
1root@debian:~# ipvsadm -Ln --rate
2IP Virtual Server version 1.2.1 (size=4096)
3Prot LocalAddress:Port                 CPS    InPPS   OutPPS    InBPS   OutBPS
4  -> RemoteAddress:Port
5TCP  10.0.0.200:80                       1        4        0      261        0
6  -> 10.0.0.129:80                       0        2        0      138        0
7  -> 10.0.0.130:80                       0        2        0      123        0

列说明：

  • CPS：每秒连接数（Connections Per Second）
  • InPPS：每秒入站包数（Packets Per Second）
  • OutPPS：每秒出站包数
  • InBPS：每秒入站字节数（Bytes Per Second）
  • OutBPS：每秒出站字节数

用途：

  • 实时监控流量
  • 性能分析
  • 容量规划

查看超时设置 --timeout

​
1root@debian:~# ipvsadm -Ln --timeout
2Timeout (tcp tcpfin udp): 900 120 300

含义：

  • tcp 900：TCP ESTABLISHED 连接超时（15分钟）
  • tcpfin 120：TCP FIN_WAIT 连接超时（2分钟）
  • udp 300：UDP 连接超时（5分钟）

规则管理命令

清空所有规则 -C

1ipvsadm -C

效果：

  • 删除所有虚拟服务
  • 删除所有真实服务器
  • 清空连接表

注意： 会中断所有现有连接，生产环境慎用。

保存规则 --save / -S

​
1# 输出到终端
2ipvsadm -S
3
4# 保存到文件
5ipvsadm -S > /etc/sysconfig/ipvsadm
6
7# 使用专用命令
8ipvsadm-save > /etc/sysconfig/ipvsadm

恢复规则 --restore / -R

​
1# 从标准输入恢复
2ipvsadm -R < /etc/sysconfig/ipvsadm
3
4# 使用专用命令
5ipvsadm-restore < /etc/sysconfig/ipvsadm

开机自动加载

 1# 保存规则
 2ipvsadm-save > /etc/ipvsadm.rules
 3
 4# 创建服务
 5cat > /etc/systemd/system/ipvsadm.service <<'EOF'
 6[Unit]
 7Description=IP Virtual Server Rules
 8After=network.target
 9
10[Service]
11Type=oneshot
12ExecStart=/sbin/ipvsadm-restore < /etc/ipvsadm.rules
13ExecStop=/sbin/ipvsadm -C
14RemainAfterExit=yes
15
16[Install]
17WantedBy=multi-user.target
18EOF
19
20# 启用服务
21systemctl daemon-reload
22systemctl enable ipvsadm
23systemctl start ipvsadm
