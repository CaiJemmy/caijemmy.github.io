路由器相关疑问

路由器的每个端口上是否有网卡

疑问：路由器端口上配IP地址，就能实现数据包的封装转发，那么路由器的每个端口上是否都有一张网卡？

解答：路由器端口本质上就是一种特殊的网卡（网络接口卡），只是在叫法、形态和功能上有所区别。

路由器端口的本质

1路由器端口 = 网络接口 (Network Interface)
2           = 物理层 + 数据链路层功能
3           = 类似于网卡的硬件模块

从硬件角度看：

  • 路由器的每个端口都有独立的物理层芯片（PHY芯片）
  • 每个端口都有独立的MAC地址
  • 每个端口都有独立的数据链路层处理能力
  • 每个端口可以配置独立的IP地址

从功能角度看：

  • 路由器端口 ≈ 服务器上的网卡
  • 只是路由器有多个端口，而服务器通常只有1-2个网卡
